# Indoor Bike Training — Issue Tracker

Public bug tracker and feature request board for the
[Indoor Bike Training](https://github.com/radekzak/indoor_bike_training) app,
a Flutter app for structured indoor cycling workouts.

This repository does not contain any source code — it exists solely so
users can report bugs and suggest features without needing access to the
main (private) development repository.

## Reporting a bug

Please [open a new issue](../../issues/new/choose) and use the **Bug report**
template. Include:

- What you expected to happen vs. what actually happened
- Steps to reproduce
- Your device/OS and app version
- Screenshots or logs, if available

## Requesting a feature

Open a new issue describing the feature and the problem it would solve.

## Before opening an issue

Please [search existing issues](../../issues) first to avoid duplicates.
