## 1.0.2+6

### Android release fixes

- Added the missing `com.android.vending.BILLING` permission — in-app purchases were failing because it was never declared in the manifest.
- Set up real release signing (keystore + `android/key.properties`, gitignored) instead of shipping debug-signed builds.
- Fixed Bluetooth scanning finding zero devices on Android 12+: the code required a location permission that the manifest itself excludes above API 30, so it could never be granted. Scanning now only requires the Bluetooth permissions, matching the manifest's `neverForLocation` declaration.

### Bug fixes

- Workout completion could stall forever just short of its total duration if you stopped pedaling near the end (its clock only advanced while pedaling), leaving the trainer stuck in ERG lock with no way out. The completion check now runs every tick regardless of pedaling.
- Reconnecting a trainer left cadence/power frozen at zero afterward — `bikeCharacteristic` was never cleared on disconnect, so reconnecting silently kept the stale, dead characteristic reference instead of the new connection's.
- A connect failure was being masked: `isBikeConnected = true` ran unconditionally after the try/catch, even on the error path.

### UX changes

- Removed the manual Pause/Start button — auto-pause via cadence already covers it — along with the redundant route/workout shortcut icons on the ride screen header.
- The Workouts tab now disables during an active ride, matching Routes.

### Structured workouts

- Only saved workouts (yours or Provided) can be ridden — no more starting an unsaved, ad-hoc interval set.
- A workout now always pairs with a loop route, so a non-loop track can't end mid-workout. A generated default 10 km loop is used as the fallback when you don't pick one.
- New "Ramp Up" / "Ramp Down" interval type with linear power interpolation, applied to all 20 Provided workouts' warmups and cooldowns.
- A congratulations popup and a new Workout History screen (name, date, average watts/cadence/heart rate) appear on completion.
- Every workout row now has an Edit action — saving overwrites in place for your own workouts, or saves as a new copy when editing a Provided one.
- Each workout row's preview now shows its FTP % range.
- Fixed a drag-vs-scroll gesture conflict in the interval template picker (templates now use long-press to drag, so a quick swipe scrolls instead).

### Tests

- Added coverage for the new workout history, workout update/overwrite, ramp interpolation, and default-loop-route logic.
